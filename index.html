03 / WIKI · INFORME PUBLICABLE

Uso de una API cognitiva en un invernadero

Informe de desarrollo, metodología, análisis, resultados, consideraciones y referencias.

1. Introducción

El monitoreo ambiental en invernaderos permite detectar condiciones que requieren revisión y comunicar resultados de manera comprensible. El caso de estudio de la guía académica plantea una aplicación HTML que interpreta temperatura y humedad y comunica un reporte hablado. Esta solución amplía el caso con la medición del pH y la generación del reporte en español e inglés.

Se implementó un prototipo de simulación, no un sistema de control físico. Por tanto, los valores representan escenarios didácticos y no observaciones agronómicas de un cultivo real.

2. Objetivos

General: desarrollar una aplicación web que interprete tres variables ambientales y presente un diagnóstico textual y hablado bilingüe utilizando síntesis de voz como capacidad cognitiva.

Específicos: incorporar pH, validar datos de entrada, clasificar estados mediante reglas transparentes, ofrecer reportes en dos idiomas y explorar las mediciones mediante un registro local con indicadores y tendencia histórica.

3. Arquitectura y tecnologías

HTML5 organiza los formularios, tarjetas e informe; CSS3 define el diseño adaptable; JavaScript valida e interpreta las mediciones, dibuja tendencias SVG y exporta CSV. La Web Speech API (SpeechSynthesis) realiza conversión de texto a voz con las voces que ofrece el navegador o el sistema operativo. localStorage conserva el historial de esta demostración en el dispositivo.

Ingresar / simular datosValidarClasificar rangosRedactar reporteLeer en voz

El motor de reglas no constituye aprendizaje automático. La característica cognitiva integrada es la síntesis de voz, que facilita una interacción accesible y multilingüe; no se ha implementado reconocimiento de voz, predicción entrenada ni una plataforma Big Data distribuida.

4. Metodología y análisis exploratorio (EDA)

Se definen tres variables cuantitativas: temperatura (°C), humedad relativa (%) y pH (escala de 0 a 14). Antes de clasificar, se verifican límites físicos plausibles para la demostración y que los datos sean numéricos. Posteriormente, cada variable se contrasta con un intervalo de referencia configurable en código.

VariableReferencia ilustrativaInterpretación
Temperatura18–28 °CPor debajo: baja; por encima: alta
Humedad relativa50–80 %Por debajo: baja; por encima: alta
pH5.5–7.0Por debajo: ácido; por encima: alcalino

Advertencia: estos intervalos son supuestos didácticos; los umbrales reales dependen de la especie, etapa fenológica, sustrato y estrategia agronómica. La medición de pH se interpreta como una lectura de sustrato o solución nutritiva, no de aire.

El módulo EDA calcula cantidad de registros, promedios, mínimos y máximos por variable, proporción de estados y evolución cronológica. La muestra se inicia con observaciones sintéticas explícitamente identificadas para poder mostrar el funcionamiento sin infraestructura adicional. No son resultados empíricos y no deben reportarse como evidencia de campo.

Estos enfoques comparten el propósito de transformar información en conocimiento accionable, pero difieren en autonomía, necesidades de datos y complejidad. El prototipo combina reglas deterministas con una interfaz de voz y proporciona una base para integrar sensores y modelos predictivos en una etapa posterior.

7. Responsabilidad y limitaciones

Los reportes no equivalen a un diagnóstico agronómico profesional. Se informa expresamente que todos los registros son simulados y que no se dispone de medición en tiempo real. No se recolectan identificadores personales. Para despliegues empresariales deben añadirse autenticación, manejo de consentimientos cuando corresponda, trazabilidad de calibraciones, seguridad en transporte, validación de sensores y control de calidad de datos.

Los textos de referencia y rangos se deben ajustar y validar junto con un especialista en agricultura antes de operar sobre un cultivo real. La síntesis de voz puede no estar disponible en algunos navegadores, o puede depender de servicios del proveedor del navegador/sistema operativo.

8. Conclusiones

El proyecto cumple a nivel de prototipo con incorporar pH y un segundo idioma al reporte de estado del invernadero. La información se comunica en forma textual y, cuando el navegador lo permite, por voz. El módulo exploratorio mejora la comprensión del comportamiento de las mediciones y facilita identificar valores atípicos frente a referencias asumidas. La principal limitación es que la fuente de datos es sintética, sin adquisición por sensores ni validación de campo; por ello, las conclusiones no pueden extrapolarse a producción.

Guía de publicación y evidencias

Esta misma página constituye la wiki o sitio web solicitado y contiene la aplicación y el informe. Para publicar el proyecto, sube index.html, styles.css y script.js a un repositorio público de GitHub y activa GitHub Pages desde Settings → Pages → Deploy from a branch. Usa la URL pública generada como enlace en el Word de entrega.
